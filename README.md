# ShutterSync React (Vite)

Converted the original static `index.html` into a small React app scaffolded for Vite.

Quick start:

```bash
npm install
npm run dev
```

Notes:
- Tailwind, Google Fonts and Font Awesome are kept via CDN in `index.html` for simplicity.
- Main app entry: `src/main.jsx` -> `src/App.jsx`.
- Components live under `src/components`.
- Styles moved to `src/styles.css` (includes the paper-doc styles from the original site).
